# TraceForge public releases and support

Official website: https://traceforge.space/

- [Signed downloads](https://traceforge.space/download/)
- [Install, verify, update and uninstall](https://traceforge.space/docs/installation/)
- [Documentation](https://traceforge.space/docs/)
- [Customer support](https://traceforge.space/support/)
- [Corresponding source, licenses and security notices](https://traceforge.space/downloads/source-and-security.html)

This repository distributes qualified release artifacts and their signatures, checksums and corresponding source. Private operator accounts and customer credentials are not included. GitHub Actions is not the build or deployment mechanism.

Use the release notes for exact platform support, component source identities and disclosed advisories. Back up projects before updating. Uninstalling does not cancel a subscription; use account billing management.
